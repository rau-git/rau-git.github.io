Unity Multiplayer Project 😼

This project was originally started as a multiplayer demonstration to go alongside my dissertation and included a test level showcasing players joining a server and performing very basic game mechanics such as collecting resources, collecting loot and attacking.

The loot system had many underlying components that came together in different ways. I enjoy designing systems this way, breaking down the system into smaller components and seperating areas that may be repurposed in other areas. Unity's ScriptableObjects were a great way to implement individual loot items into the system by creating various levels of inherited functions and variables..etc...
Loot containers (or chests) also include their own inventory component, which their own loot generation script uses to place the generated items into. To select which loot is able spawn inside a container there is an attached loot table ScriptableObject which includes a dictionary where the droppable items are stored as keys and their 'roll weight' is stored as the associated value. Doing it in this format works great as the key in a dictionary needs to be unique, so an item can't be accidently placed in a loot table multiple times.
