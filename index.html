Survival Multiplayer Demo 🪓

Unity | C# | Fish-Networking

I made this originally to go alongside my disseration for final year uni, but I enjoy adding little features here and there as practice. The notable aspect of the project was transferring what I know to a multiplayer environment and worked on some basic surival game features like loot generation, gathering, hunger/thirst etc.

Roguelite Game 🤖

Unity | C#

This was done as part of a group project at university and the player is a little robot cat thing that destroys other more eviler robots. My part involved making the usual player movement, player attacks, progression, game managers, enemy ai, enemy attacks, player customisation, and some other stuff. I also made a prototype for random dungeon generation but it didn't make it in the end because there wasn't enough time to make the art for it :c

Spooky Game Jam 🎃

Unity | C#

A short Unity project for a spooky game jam I participated in. The idea I had was to implement a system where the player would take pictures of monsters to capture them inside images, the camera takes an image, captures the spooky dude (kills them) 😼 and prints a photo with some information attached.

Rat Game Jam 🐭

Unity | C#

You run around a little island as an evil rat, shooting your rat poison at people and turning them intro tiny rat minions. These lil rats follow you about and you can use them to cause a rat explosion or block enemy attacks. i love rats...

Current Project 👻

Unreal Engine | Blueprints | C++

Currently I'm working on learning Unreal Engine by making a ghost hunting game, like Phasmophobia. So far I've been building the base Ghost AI, interactable objects, ghost events and the whole lights system where the ghost (or players) can turn on/off lights or the circuit breaker and stuff, it's also made to work in multiplayer too so that's pretty epic. It's fun adding random mixamo fighting animations so the ghost appears and flying kicks people, there's a serious lack of martial arts in these games.

AI Demo

Unity | C#

I made this little AI demonstration for a university project where the bunny will set tasks based on current needs (hunger/thirst) or gather wood and build his house when those needs were at a satisfactory level. It should be said that this demo had to be designed using FSMs as per the course requirements but I have also done other projects with AI using behaviour trees, which I preferred using...🙊.
